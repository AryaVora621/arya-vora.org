# Arya Vora

The source for [arya-vora.org](https://www.arya-vora.org), Arya Vora's personal site. Most of the page is about roboPet, the four-legged robot he is building: a scroll-scrubbed film, a line-drawn 3D model you can turn and pull apart, its parts and its build log. Below that are his other projects, a breadth-first search demo you can run, an About section and contact details.

Next.js 16 (App Router), React 19, Tailwind CSS v4 and three.js. Black and white only; the rules are in [DESIGN.md](DESIGN.md).

## Development

```sh
npm ci
npm run dev
```

`npm run dev` starts `next dev` and prints the local URL to open. This Next.js version has breaking changes from older releases, so read the matching guide in `node_modules/next/dist/docs/` before touching a Next API (see [AGENTS.md](AGENTS.md)).

## Fonts

Atkinson Hyperlegible Next for all text and Atkinson Hyperlegible Mono for part numbers, code and computed counts. Measurements such as 7.2 V stay in the sans, because the mono face gives the decimal point a full cell (DESIGN.md section 4). Both load through `next/font/google`, which downloads them at build time and serves them from this site, so visitors' browsers never contact Google. The social image cannot use `next/font`, so it reads static TTF cuts from `assets/fonts/` (provenance and the SIL Open Font License are in that folder).

## Checks

```sh
npm run check:design
npm run lint
npm run build
npx playwright install chromium
npm test
```

`npm run check:design` runs `scripts/check-design-rules.mjs`, which fails on anything DESIGN.md bans: colors outside the five tokens, gradients other than the search-demo hatch, shadows, blur, uppercase or tracked labels, mono outside its allowed selectors, em and en dashes, arrows, middle dots, banned words and stale facts. It also runs as `prebuild`, so a failing check stops `npm run build`. Pass file or folder paths to scan only those.

`npm test` runs the Playwright suite in `tests/` against a production server on port 3100, so run `npm run build` first after source edits.

## Deploys

Commits on `main` deploy to production on Vercel at https://www.arya-vora.org. The apex domain arya-vora.org redirects there.
